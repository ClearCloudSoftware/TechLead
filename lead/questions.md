# questions.md — the grill question bank

**Empty by design.** These are *the owner's* questions — the ones that come from things that have
bitten him — not generic PM questions. They accrete from real feature grills (E6.1) and from worker
escalations fed back (§2.5). The bank is the asset, not the answers (§2.6).

Shape per entry (see [SHAPE.md](SHAPE.md)):

```
### <question, phrased the way the owner actually asks it>
hits: 0   last: —
_scar:_ <the thing that went wrong once and made this worth asking>
```

The grill's inference pass reads this file. Curate it like any other judgment file — prune questions
that stop earning their `hits` (§8.12).
